# Sotorasib Interactive E-R Explorer — Shiny App

Interactive viewer built on top of the validated Python pipeline outputs for sotorasib exposure-response analysis and dose optimization.

## Quick Start

```r
# From the project root (05-sotorasib-exposure-response/)
shiny::runApp("shiny_app")
```

**Prerequisite:** The Python pipeline must be run first to generate CSV outputs:

```bash
cd 05-sotorasib-exposure-response
bash run_all.sh
```

If the CSVs are missing, the app displays a professional "Pipeline Not Run" screen with instructions.

## Requirements

- R >= 4.4.0
- Packages: `shiny`, `bslib`, `DT`, `plotly`, `readr`, `dplyr`, `tidyr`

Install all at once:
```r
install.packages(c("shiny", "bslib", "DT", "plotly", "readr", "dplyr", "tidyr"))
```

## Architecture

This app is a **read-only viewer** on validated Python pipeline outputs. It does NOT re-simulate PK or E-R in R.

- All CSV files are generated by the Python scripts (`analysis/01-06`)
- Model parameters (E0, Emax, EC50, gamma, alpha, beta_cmax, beta_cpi) are read from `outputs/tables/model_params.csv` — never hard-coded in R
- If the Python team changes a parameter, the Shiny app picks it up automatically on next pipeline run

### CSV Files Read

| File | Content | Used In |
|------|---------|---------|
| `virtual_patients.csv` | 2,500 virtual patients | All tabs |
| `pk_summary_by_dose.csv` | GM AUC/Cmax per dose | Dose-Exposure |
| `pk_anchor_vs_simulated.csv` | Published vs simulated | Validation |
| `orr_by_exposure_quartile.csv` | ORR by AUC quartile | Efficacy |
| `safety_by_exposure_quartile.csv` | Hepatotox by Cmax quartile | Safety |
| `dose_optimization_summary.csv` | ORR, hepatotox, TI, NNT, NNH | Benefit-Risk |
| `benefit_risk_comparison.csv` | Published vs simulated | Benefit-Risk |
| `covariate_effects.csv` | Forest plot data | Covariates |
| `model_params.csv` | E-R model parameters | What-if overlay |

## Features

### Top Metrics Card
Selected dose, predicted ORR, predicted hepatotoxicity, median AUC, and therapeutic index. Updates in real-time as inputs change.

### Patient Profile (Sidebar)
- **Dose selector:** 180, 240, 360, 720, 960 mg
- **ECOG status:** All / 0 / 1 / 2 — filters virtual patients
- **Prior CPI toggle:** filters to CPI-positive patients
- **Compare mode:** overlay a second dose
- **Advanced:** manual AUC/Cmax input for direct E-R evaluation

### Tab 1: Dose-Exposure
- Boxplot of AUCss by dose from virtual patients (plotly)
- Published anchors as diamonds
- Filtered subset median highlighted
- PK calibration table (published vs simulated)

### Tab 2: Efficacy
- ORR by dose bar chart with published reference points
- Exposure quartile analysis (960 mg)
- E-R curve overlay using model params from CSV
- Subset prediction highlighted on curve

### Tab 3: Safety
- Cmax quartile hepatotoxicity rates
- 2x2 risk stratification matrix (High/Low Cmax x CPI status)
- Subset-specific hepatotoxicity prediction card

### Tab 4: Benefit-Risk
- Scatter: ORR (y) vs hepatotox (x) per dose
- Published (diamonds) vs simulated (circles)
- TI / NNT / NNH metrics table
- Subset position highlighted
- Download CSV button

## Patient "What-If" Overlay

When the user selects covariates (ECOG, CPI status), the app:
1. Filters `virtual_patients.csv` to the matching subset
2. Shows the exposure distribution of that subset (median AUC/Cmax)
3. Computes predicted ORR and hepatotox using E-R formulas on the subset's median exposure
4. Highlights the subset on all plots

**Advanced mode:** User can enter AUC/Cmax values directly, bypassing covariate filtering.
